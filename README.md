# Point of Sale Mini System

A lightweight Point of Sale (POS) system built with C# for small retail businesses and vendors.

## Overview

This Point of Sale Mini System is designed to provide essential POS functionality for small to medium-sized retail operations. It offers a streamlined interface for managing sales transactions, inventory, and basic business operations.

## Features

- **Sales Management**: Process customer transactions quickly and efficiently
- **Inventory Tracking**: Monitor product stock levels
- **User-Friendly Interface**: Intuitive UI for fast-paced retail environments
- **Transaction History**: Keep detailed records of all sales
- **Basic Reporting**: Generate sales reports for analysis

## Technology Stack

- **Language**: C#
- **Platform**: .NET Framework

## Getting Started

### Prerequisites

- .NET Framework (version as specified in the project)
- Visual Studio or compatible IDE

### Installation

1. Clone the repository:
```bash
git clone https://github.com/liewvk/PointOfSaleMiniSystem.git
```

2. Navigate to the project directory:
```bash
cd PointOfSaleMiniSystem
```

3. Build the project:
```bash
dotnet build
```

4. Run the application:
```bash
dotnet run
```
